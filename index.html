What is simar-ui?

A set of custom-styled form controls. Each one is a real HTML element underneath, so it still works without CSS or JavaScript.

Does it work with a keyboard?

Yes. Keys, faders and knobs all take focus and respond to the arrow keys, and every control shows a focus ring.

Can I change the colors?

The lit color, accent and cap tones are CSS custom properties, and data-lit or style="--lit: …" recolors any part of the page.

Code

Preloader

A spinner and a progress bar, for when something is loading. The bar is a native <progress>, so it works without JavaScript and is announced as a progress bar. Leave off value when the length isn't known. Motion stops with prefers-reduced-motion, and data-paused freezes it.

Tooltips

Add data-tooltip to a button, link or radio key. It shows on mouse hover and on keyboard focus, Esc dismisses it, and you can move the pointer onto it. Give a key with no visible text an aria-label as well, so it has a name without JavaScript; then its tooltip is added automatically.

Date range

Two native <input type="date"> fields stay the source of truth, so typing, min/max and form submission all work. With JS, the calendar button opens a range picker: click a start day, then an end day.

Configuration

Everything is set with HTML attributes. Native ones (min, max, step, name) keep their usual meaning.

AttributeOnEffect
steprangeValues snap to each step. Add data-marks to draw a mark at each one.
data-marks / data-marks="5"faderTick marks at every step, or at N evenly spaced points.
data-ticks="12"knobNumber of tick marks around the dial.
data-labels="Off,Low,High"knobTurns the knob into a stepped selector with a click per label.
data-unit, data-prefixfaders, knobs, rangesText added around the readout, such as % or $.
data-lit="blue" or style="--lit:#ff4d6d"any elementHighlight color for it and everything inside. Presets: blue, amber, red, violet.
data-haptic="off"any elementVibration for it and everything inside: on, off, tick, click, heavy, or milliseconds like 10,30,10.
data-pausedspinner, loader (or any ancestor)Freezes the loading motion. With prefers-reduced-motion it never moves at all.
<simar-spinner>, <simar-loader value="64">pagePreloaders. Leave value off for a bar of unknown length.
<simar-checkbox>, <simar-switch>pagelabel, name, checked, disabled, indeterminate (checkbox). A switch is a checkbox with role="switch".
data-tooltip="Text"button, link, radio keyA tooltip on hover and keyboard focus (Esc dismisses). On a tag: tooltip="Text".
nolines / nocopycode blockLeave off the line numbers (shown on blocks of two or more lines) or the copy button.
data-months="2"date rangeMonths shown side by side in the calendar.
data-max-span="7"date rangeLongest allowed range, in days.
data-first-day="1"date rangeFirst day of the week: 0 is Sunday, 1 is Monday.
name="faq"accordion itemItems sharing a name open one at a time. Leave it off to let several stay open.
command="show-modal" commandfor="id"buttonOpens the dialog with that id, no JavaScript needed.

Attributes: label, name, min, max, step, value (or low/high, from/to), unit, prefix, marks, ticks, labels, lit, haptic.
SimarUI.init(element)scriptEnhances markup added after page load, such as from a framework.
