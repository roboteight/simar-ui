Suggested flows

Four common journeys, assembled only from simar-ui components. Each one is plain HTML first: it works with no script, submits as a normal form, and the script only adds the steps and messages. Copy the markup and change the words. Back to the components.

  • Sign in
  • Checkout
  • Onboarding
  • Empty and error pages

Sign in

Two fields, a password you can reveal, and one clear way forward. A failed attempt is an alert that is read out as it appears, and it says what to fix without saying which of the two was wrong. The link to reset a password sits next to the field it is about. Components: form control, input group (password reveal), switch, buttons, alert, validation.

Notes for your own version:

  • Name each field with a visible label, never only a placeholder.
  • Set autocomplete (username, current-password) so password managers and browsers can fill it.
  • Keep the alert in the page from the start and reveal it, so it is announced when it appears.
  • Offer the password reveal as a real button with aria-pressed.

Checkout

A wizard in four steps: cart, shipping, payment and review. Without script it is one long form with every step showing. With script it shows one step at a time, checks each before moving on, and moves focus to the new step's heading. Components: wizard, steps, tile list, form control, number stepper, buttons, status message.

A short welcome that says how long it takes, asks one thing at a time, and lets people skip. It never blocks: "Skip for now" is a real link. Components: steps, chips, check list, buttons.

Empty and error pages

What a page says when there is nothing here or something went wrong. Each one says what happened in plain words, whose fault it is only if it helps, and gives one way forward. On a real page the title is the page's h1. Components: empty state, alert, buttons.
