# Responsive by default

Every page and component works from phone to desktop, unless told otherwise.

- Mobile first. Breakpoints (in rem): sm 36, md 48, lg 62, xl 75, xxl 87.5. The class names borrow from Bootstrap (credit it; the code is our own).
- No horizontal scroll at 320px. Floating UI (menus, tabs, buttons) must not cover content on small screens.
- Check phone, tablet and desktop widths in a real browser before calling a page done.
